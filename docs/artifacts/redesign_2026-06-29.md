### model/models.go — HotMovieItem 重定义
```go
type HotMovieItem struct {
    MovieID        int     // id
    Name           string  // nm
    Img            string  // img (大图)
    Score          float64 // sc
    Version        string  // version
    Star           string  // star
    ReleaseDate    string  // rt
    ShowInfo       string  // showInfo
    ShowState      int     // showst (3=热映, 4=预售)
    Wish           int     // wish 想看数

}
```
